# 微信原生经营工具阶段验收

日期：2026-11-07。主线为原生小程序及既有CloudBase环境，18个原生页面、4个底部导航。全程使用模拟资料、价格、库存、物流与售后，不接支付；没有操作用户浏览器。

## 本次交付

- 完整商品编辑：分类、简述、标签、详情、大小、储存、资料卡、采收步骤，以及两种固定规格的名称／重量／提示／价格。新增先保存草稿，配置库存和素材后再上架。
- 已保存商品预览：授权商家可核对自己的草稿、下架和在售商品；不通过公开目录泄露草稿，不写买家购物记录，不提供草稿分享。返回编辑页保留未保存内容。
- 商品变更记录：与商品写入同事务，保留最近50条的字段与名称／价格／状态／素材摘要；旧商品不补造历史，不保存完整长文快照或身份／签名URL。使用现有受控meta集合，单份记录最大128KiB，无新增集合、索引或共享环境权限。
- 原生记录入口：商品编辑页进入商品／库存记录，管理员从采购者编辑区进入授权记录。库存及授权记录支持游标翻页、去重、错误重试和账号切换清空。
- 工作台：商品、订单、售后各自搜索和状态筛选，待处理数量基于完整授权集合；选定订单与筛选在同账号刷新后保留。内部备注限订单权限，售后单权限不可读写，买家DTO不包含备注。
- 冲突保护：未保存商品、素材和库存互不抹掉；库存保留其原版本。未保存备注保留独立版本基线，刷新不会将旧稿配上新版本覆盖其他设备；保存期间不接收后续输入。
- 买家体验：首页与店内支持分类、搜索、有货筛选；修复连续换关键词只在旧结果中搜索。订单展示实际保存的生成、发货、收货、售后及取消回库记录；时间统一为北京时间，不虚构物流节点。
- 手机布局：完整编辑按区块组织，三个工作台入口直接可见，横向筛选按钮按文字宽度排列；模式标记与模拟说明继续保留。

通过已授权微信开发者工具CLI调用实际云函数，不操作浏览器。仅增量部署本项目market函数；没有变更provision、其他应用函数、共享存储规则、套餐或执行角色权限。

以已验证管理员的真实微信会话作为模拟买家及管理者，独立创建“景泰苹果·经营演示”测试商品，完成17项检查：完整草稿保存、买家不可见、管理预览、创建历史、详情字段修改历史、库存调整记录、上架后买家读取、创建模拟订单、管理备注保存与读取、买家备注隔离、旧版本备注冲突、模拟发货／收货／售后、库存预留记录、下架、四次商品变更历史及原公开目录保留。

测试完成后，该测试商品保持下架，原公开目录仍为六款；只消耗测试商品的模拟库存，没有重置原商品余量。测试订单保留完整模拟收货及售后处理过程。随后通过原生工作台页面方法再次搜索选中此订单、填写并保存内部备注，云端成功后选中状态和筛选保留，订单版本递增。

官方模拟器已读取并查看工作台、完整商品编辑、已保存下架商品预览、商品／库存记录、买家订单过程等页面；截图和运行结果在本机忽略目录。已生成新的开发预览二维码供管理员微信扫码，二维码不提交公开仓库。

## 手机验收路径

1. 使用本次开发预览进入“我的”，微信登录后打开“商家工作台”。
2. 在商品页新增模拟草稿，修改规格／详情／资料卡／采收步骤并保存；预览核对，配置模拟库存、上传有权使用的模拟素材后再上架。库存需要单独保存。
3. 打开商品／库存记录核对本次变更；已有商品在此功能发布前的编辑不会补造商品记录。
4. 从买家首页或店铺搜索商品，按店加入购物车并模拟下单；工作台搜索订单，填写内部备注、模拟发货。
5. 买家确认模拟收货并申请售后；工作台处理后，买家查看结果及过程记录。内部备注只在工作台可见。

用户之前已确认手机能看到商品和工作台，本阶段尚未让用户重新完成上述全部手机步骤。真实第二采购者、两台实际设备的交叉操作和手机选取／播放素材仍待补验，不能由管理员兼买家或自动化夹具替代。
