# 原生微信云媒体验收（2026-11-07）

本轮范围是原生微信小程序的商家商品展示素材，使用模拟资料，不接支付。旧Sites网页后台未迁入这个CloudBase入口；仓库默认仍是本机模式，私有部署包和运行记录不进入Git。

## 已实现

- 商家选择相册或拍摄，上传和更换商品图片、MP4视频；默认图片恢复、视频移除、独立预览续签。
- JPEG/PNG/WebP最大5MiB，MP4最大20MiB；相册视频选择最长120秒、拍摄最长60秒。后端验证类型结构、实际大小及分块哈希，不把选择器限制称为服务端时长鉴定。
- 256KiB分块、并发3，通过云函数传输；真实进度、校验阶段、取消、失败重试与断点复用。相册返回、刷新预览和保存库存不抹掉未保存的价格与素材。
- 商品归属、分别授权、会话及撤权保护；上传后须保存商品才改变商城展示。最终对象随机不可变，不发客户端上传签名。
- 买家详情显示云图片与视频，可放大图片、查看视频来源说明；链接不可用时保留商品价格与库存，并允许手动刷新。
- 更换图片后旧订单保留原图。曾保存绑定及历史缺少安全删除记录的素材不删除；新的未绑定素材支持取消清理，绑定与取消的双向竞争受同一媒体文档写冲突保护。

## 存储边界与清理

没有修改共享存储规则、13个数据库集合规则、其他项目云函数、IAM或套餐。本环境现有存储为PRIVATE。受控探针的第一个对象操作直接使用和商品媒体相同的`wx-server-sdk.uploadFile`，没有先用其他SDK预注册所有权。实测服务端短URL可读、去掉签名的URL为403；客户端持fileID可换取链接和下载，直接覆盖失败（-503002）、删除失败（status 1）；服务端校验探针原字节完整并完成清理。

因此本功能是**公开展示用途的商品素材通道**，不承诺原始fileID的读取保密。192位随机最终路径降低枚举风险，商家归属/发布绑定决定业务API可发现性；下架不能撤回别人已保存的文件或链接。权限机制差异的底层原因没有得到证明，不把推测写成事实。订单和售后业务数据仍采用服务端身份隔离，不能把这个通道用于私人凭证。

媒体就绪标记使用`server-owned-display-v1`，本应用/环境匹配且核验不超过7天；过期需重新只读检查。规则核验是时点快照，无自动续期。规则不满足时上传/绑定关闭，商品仍能以默认示意图和明确提示展示。

大文件测试发现旧清理流程会因重复删除已不存在的块提前失败，已修复为优先最终文件、逐文件严格确认、分批继续及持久清理检查点。非0返回不会被假定成已删除，权限拒绝不会被吞掉；暂未确认的残余以cleanupPending及数字状态码保留。完成上传后不再重复删除已成功清掉的块，清理更新不覆盖并发商品绑定。旧20MiB测试对象已返回finalDeleted:true，并通过官方存储只读列表核对其目录为0文件；旧分块的非0删除结果仍保留待核对检查点。修复后重新上传一张未绑定图片，取消返回finalDeleted:true、cleanupPending:false。

意外杀进程的暂存块尚无自动生命周期清理；15分钟业务过期不代表对象自动删除。GitHub备份源码与测试，运行时云媒体不随代码进入公开仓库。用户现有体验环境的实际有效期仍以微信控制台为准，本轮未购买或续费。
