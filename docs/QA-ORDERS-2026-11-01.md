# V0.6 云端模拟订单与售后验收

日期：2026-11-01（Asia/Shanghai）。本轮使用模拟资料，不接支付，不生成真实物流、退款或补发。按照用户要求，全程通过命令行与 API 实施，不操作用户浏览器或 Computer Use。

## 本轮实现

- 买家按服务端当前商品价格和示例地区运费下单；保存商品、规格、数量和金额快照。
- 同一登录身份从独立客户端读取相同订单、发货和售后记录；云端不导入本地旧订单，不自动生成样例单。
- 后台管理订单、内部备注、模拟发货和整单售后处理；买家可取消符合条件的订单、申请与撤回售后、查看处理意见和历史。
- 买家与商家归属隔离；内部备注不出现在买家接口。版本冲突不覆盖，重复请求不重复建单，账号切换及权限收缩立即清除旧私有内容。
- 购物车、收藏、足迹与客服仍为本机记录；跨商家商品暂需分开下单。没有云订单批量删除入口。

## 本机 Worker 集成流程

命令行脚本只允许 `http://127.0.0.1` 或 `http://localhost` 根地址，并拒绝重定向，避免模拟身份头误发到真实站点。它使用本机已有模拟管理员和两名临时模拟买家，不访问线上客户资料。

1. 无身份读取订单401；买家取得服务端报价并创建订单201。
2. 同请求重放200且订单编号不变；另一个独立HTTP请求读到同一订单。
3. 第二买家不能读取第一买家订单（404），不能读取或修改后台（403）。
4. 模拟管理员填写 `DEMO-` 运单发货；买家独立读取到已发货状态。
5. 买家申请售后；旧版本处理409，新版本处理成功；买家读到回复和申请／处理历史。
6. 第二笔订单演示申请、撤回售后及取消；独立读取确认最终状态和历史。

脚本只向本机模拟库新增两笔测试订单，没有改动既有商品或向线上灌入测试订单。本机预览验收后已停止。

## 验证限制

- 本轮没有真实手机或桌面浏览器点击、布局、登录跳转及刷新验收；没有截图，不将控制器或HTTP测试称为实机验证。
- 本机HTTP中的身份头仅模拟可信入口；不代表对生产登录流程的验证，也没有新增生产认证绕过入口。
- 线上仍保持原有私有访问范围；手机与电脑需登录同一有权访问该站点的账户。旧浏览器演示订单不会随登录上传。
- 断网重试标识保存在本标签页会话存储中。清除会话存储前应先确认云订单结果；云订单数据本身不依赖浏览器保存。
- GitHub备份保存源码、迁移和文档，不是D1／R2运行数据备份。真实运营仍需独立备份恢复、库存与实际履约方案。
