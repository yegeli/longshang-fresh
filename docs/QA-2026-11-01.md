## 自动化与构建

- 68 项仓库测试通过，包括 11 组云客户端测试、9 组云 API 测试，以及静态模式显式标记回归。
- TypeScript `tsc --noEmit` 通过，Vinext 构建通过。
- 云 API 测试使用实际生成的 SQL 迁移和 SQLite，D1／R2 为适配器；覆盖一次性管理员绑定、角色、跨账户拒绝、版本冲突、上传限制、失败清理和素材可见性／Range。
- 独立临时检查补验商家角色撤销即时拒写、最后一条在售引用撤下后素材受限、私有 HEAD 先授权后访问 R2，以及长度谎报和异常信息不泄漏。
- 后台 VM 检查覆盖匿名门禁、无标记 404／5xx 不回退本机、409 保留输入和预期版本、明确放弃后重新载入。媒体事件为桩，实际媒体证据见下表。

这些结果不等同于所有账户和设备均通过真实托管测试。不同商家越权、故障注入及并发拒绝主要由自动化覆盖，本次没有声称用多个真实托管商家账户逐项复验。

| 场景 | 操作与观察结果 |

| 独立商品读取 | 不使用浏览器存储的 HTTP 客户端读取已发布目录，得到同一商品价格，验证结果来自云端而非当前页面内存 |

| 本地云流程 | 本地预览也完成商品改价、图片／视频上传与发布，并由独立客户端读到相同结果；本地资源与托管资源仍相互独立 |

独立托管 HTTP 验证使用私有站点服务访问机制，仅通过站点访问边界，没有商家用户身份。它验证业务 API 可按已发布规则读取，不表示访问凭据能够修改商品，也不表示站点已公开。记录不保存或展示该凭据。

新买家标签页与独立 HTTP 客户端证明服务端持久化和跨客户端读取；它们不是两部真实设备。本次没有操作真实手机。手机可使用有站点访问权限的同一账户登录访问，但移动端布局、文件选择和视频兼容性尚未实机验收。

## 测试素材与后续检查

纯色测试视频仅验证上传与播放，不是采摘或产地影像。验收后已解除商品的视频绑定，保留上传机制和 R2 对象。随后从云目录回读确认六款商品仍为已发布，苹果版本为 3、保留云图片且不再绑定视频。未被其他在售商品引用的对象按媒体 API 权限规则仅所有者或管理员可读；本次未另行声称在解除后重新执行了匿名素材请求。

本次未引入历史 Pexels 视频或封面。测试图片沿用项目原有 Unsplash 来源记录，不代表景泰实拍；[第三方素材说明](../THIRD_PARTY_NOTICES.md) 与各素材许可继续适用。

待补验的实际场景：真实手机访问与上传／播放、不同真实设备读写、多商家托管账户的越权拒绝、完整退出／首次登录，以及备份恢复演练。订单服务、真实支付、物流、素材审核和自动回收仍是后续实现事项，不在本次通过范围。
