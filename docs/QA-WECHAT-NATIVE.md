# 微信原生工程阶段验收

本轮交付的是原生小程序源码、完整模拟业务和微信登录服务端实现。2026-11-02 已根据用户提供的微信后台截图配置真实AppID，并重新通过原生源码与官方离线编译检查；用户完成桌面工具登录与服务端口授权后，已通过官方CLI实际上传开发预览并生成二维码。用户随后确认手机扫码“已进入首页，能看到商品”；订单至售后的完整真机操作尚待验收，未提交审核或正式发布。历史 `chatgpt.site` 手机网页不计作微信小程序交付。

## 已实现

- 13个原生页面、4个底部导航：首页、产区与详情、店铺列表与详情、商品详情、购物车、结算、订单列表与详情、售后、我的、完整指南。使用WXML／WXSS／Page／App，没有web-view壳。
- 六款模拟商品、本机首次20／12份库存；同店结算、价格与库存快照、幂等下单、取消批次检查、模拟发货、收货、售后及结果回看。刷新不重置库存。
- 本机模拟和云模式明确区分；云模式通过 `wx.login` 接口取得项目会话，不携带Sites服务密钥，不上传本机旧数据。云失败不切回本机。
- 微信 code 交换、不透明会话、哈希持久化、到期与退出撤销、重复 code 保护、独立微信身份和公开Worker入口。采购者或管理员不通过客户端字段、相同邮箱、首个访客自动授予。
- 购物车版本冲突、账号切换、旧读取、下单响应丢失、存储失败与订单成功后的清理失败处理。只有本机模拟模式显示“模拟商家发货／处理售后”按钮。
- 项目AppID配置、源码包体检查、官方离线编译、受控命令行预览脚本及GitHub阶段备份流程。
