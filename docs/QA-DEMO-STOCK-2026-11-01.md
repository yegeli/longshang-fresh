# 云端模拟库存验收 · 2026-11-01

用户明确要求配置模拟库存，以便手机直接体验下单、发货、收货、售后；不接支付，通过命令行备份 GitHub，不操作浏览器。

## 实际上线结果

托管版本12于北京时间2026-11-01晚发布，保留原站点、原有单所有者访问范围。六款已发布模拟商品（苹果、枸杞、梨、土豆、玉米、洋葱）每款 `small=20`、`family=12`，合计192份，初始库存版本均为1。批次以 `DEMO-SETUP-V1-` 标记，采摘日期留空，不虚构采摘事实。

配置前直接查询托管数据库确认没有库存记录；通过经授权、临时密钥保护的维护接口配置后，公共库存 API 和数据库查看器都读到上述数量。`setup_operations` 只有一次完成记录，`inventory_events` 有六条系统配置审计。配置前后六条商品完整数据库行一致，归属、价格、素材绑定和商品版本均保留。没有在托管站点生成测试订单或模拟真实访客身份。

配置使用独立服务授权，不改变买家与商家的登录权限。移除变量并重新部署后发现原密钥仍能读取完成摘要，因此采用显式无效值 `disabled` 覆盖临时密钥和有效期，再部署并用原密钥核验返回404；原管理员设置保留。公共库存仍保留20／12份，未经访客登录的管理与购物资料接口继续拒绝访问。

手机指南更新为七步，包含真实后台入口、按钮名称、同一账号双角色体验和切换页面后的刷新提示。后台暂未实现hash深链，所以指南链接使用后台实际入口，再提示选择“订单管理”或“售后管理”。

## 验证边界

没有操作浏览器或真实手机；HTTP与自动化检查不等同真实设备触控、登录及播放验收。现有受邀范围内同一管理员账号可在商城下单并切换后台处理，普通买家不会因此获得管理权限。库存消耗后按最新余量显示，不保证以后始终维持192份。
