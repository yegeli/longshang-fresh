# 陇上鲜集 / Longshang Fresh

从甘肃景泰起步的地方特产商城开源项目，逐步连接商品、产地内容、采购与订单服务。

**当前主线：微信原生小程序工程。** `miniprogram/` 已实现21个原生页面，覆盖买家、商家和客服入口，包含完整模拟购物流程。独立HTTP接口在 `wechat-worker/`，微信云开发适配在 `cloudfunctions/`。2026-11-02 已用实际AppID和已登录的官方开发者工具通过命令上传开发预览，成功生成手机预览二维码；用户已确认手机扫码可进入首页并看到商品，订单至售后的完整真机操作仍待验收，未提交微信审核或正式发布。这与下方历史手机网页是两个入口。

开发流程和验收标准见 [微信小程序开发流程](docs/WECHAT-DEVELOPMENT.md)。默认是明确标识的本机模拟模式，不付款、不会同步到历史网页；真实云同步需要对应环境部署、访问规则核验和实机联调。独立HTTP路径另外需要服务端微信密钥，CloudBase路径使用微信云函数的可信身份。

已增加微信云开发适配与原生商家工作台：支持采购者自己的商品、价格、库存、模拟发货和售后，管理员按已验证的微信账户编号绑定采购者并分配权限。CloudBase路径使用微信云函数提供的可信身份，不需要将AppSecret发给客户端；独立HTTP路径继续保留。部署与实际验证状态见 [微信云端接入](docs/WECHAT-CLOUD-SETUP.md)。

2026-11-07 已完成真实CloudBase部署，六款模拟商品及库存已初始化，实际云端的下单、幂等扣库存、发货、收货和售后链路通过。用户已确认新版手机预览能看到商品和商家工作台；手机逐步业务操作仍待验收，尚未正式发布。源码默认继续保留本机模式，私有环境配置不入Git；历史网页后台不是这个CloudBase入口。详见 [微信云端验收](docs/QA-WECHAT-CLOUD.md)。

原生商家现可在商品编辑页上传、更换图片和视频，再保存商品供买家查看。素材继续使用模拟资料，不接支付；上传、替换、旧订单图片及视频分段读取已完成真实云端联调。操作与具体边界见 [原生云媒体验收](docs/QA-WECHAT-MEDIA.md)。

原生经营工具继续补齐：分类、规格、大小、标签、详情与采收步骤可完整编辑；已保存草稿可由授权商家预览，商品／库存／采购者授权记录可查；工作台支持搜索、状态筛选、待处理数量和内部订单备注。买家订单显示已发生的状态与售后记录，首页及店内支持组合筛选。结果与未验事项见 [原生经营工具验收](docs/QA-WECHAT-OPERATIONS.md)。

原生客服与店铺资料已接入CloudBase：买家可从商品、店铺或自己的订单咨询，在“我的咨询”查看回复；采购者在工作台回复、结束或重新开启咨询，未读标记按会话同步。具有商品权限的采购者可修改本店名称、介绍、咨询说明和上传／更换图片；有在售商品时同步到买家入口。文字消息在打开页面或手动刷新时更新，不包含订阅推送、自动回复或附件。现有 `aftersales` 权限对应“售后与客服”。详见 [客服与店铺验收](docs/QA-WECHAT-SUPPORT-SHOP.md)。

```sh
npm install
npm run build:miniprogram
npm run wechat:configure -- --tourist
npm run check:miniprogram
```

生成本机配置后，在微信开发者工具导入仓库根目录。取得真实AppID后用 `npm run wechat:configure -- --appid` 加实际编号替换游客配置；本机配置和凭据不进入Git。入口包括首页、产区、采购者店铺、商品详情、购物车、结算、订单、收货、售后、我的和完整指南。模拟订单详情提供明确标记的模拟发货与售后处理入口，云模式隐藏这些客户端操作。

后续每个完整阶段都会通过命令提交、推送GitHub并核验CI；源码检查、官方编译、真实微信登录和手机扫码分别记录，不能互相替代。

## 完整体验一次

1. 管理员录入模拟采购者并分配商品、订单、售后权限；采购者首次可信登录绑定身份。已有管理员也可直接管理其模拟商品。站点访问授权仍独立管理。
2. 采购者保存商品、示意图片及有权使用的视频并上架，在“库存批次”核对模拟余量后保存；新增商品默认0库存。六款内置演示商品支持经所有者授权的一次性模拟库存配置，已配置的数量不会重置。
3. 买家从产区进入采购者店铺看详情，收藏或加入购物车；不同店铺分别选择，使用示例地区生成模拟订单。
4. 采购者在订单详情记录模拟物流；买家刷新后在“待收货”确认模拟收货，状态变为“已完成”。
5. 买家从订单提交模拟售后，采购者在售后后台填写意见，买家查看最新结果。确认收货后仍能申请售后。

买家“客服与帮助”有完整体验指南，后台首页有准备和处理入口。所有商品、金额、物流和业务操作均为模拟。

## 历史网页已实现的范围

- 买家五入口：逛好物、特产馆、逛产区、购物车、我的；首页、产区详情、采购者店铺和商品详情相互连接，支持搜索、分类、收藏和足迹。
- 景泰展示当前上架商品，定边为筹备示意；店铺按商品真实归属生成，不伪造多个采购者。店内支持分类与“只看有货”，返回列表保留当前筛选和滚动位置。
- 采收视频沿用商品已保存的素材绑定，没有视频时显示待补充。触控按钮、输入字号、窄屏换行和手机底部安全区已优化；真实设备待验。
- 六款模拟商品模板：苹果、枸杞、梨、土豆、玉米、洋葱；后台可新增商品、编辑两种规格与价格、保存草稿、上架和下架。
- 图片预设与文件上传、视频上传；保存并上架后，商品详情和对应产地内容读取同一素材绑定。
- 同一商家的多商品、多规格合并模拟订单，只计算一次演示运费；服务端重新报价并保存下单快照，改价或下架不改变旧单。跨商家商品暂需分开下单；购物车可“只选这家”，其他店铺的商品继续保留，店铺关系暂时无法确认时不提交新订单。
- 云端与本机后台支持订单备注、模拟发货和整单售后处理；买家可确认模拟收货、申请或撤回售后，并查看处理意见和历史。内部备注只向有权限的后台显示。
- 云 API 支持平台登录状态、D1 角色与商品归属、版本冲突检查，以及 R2 素材上传和受控读取。普通登录账户无管理权，商家仅管理自己的商品与素材，管理员可管理全部商品。
- 云端后台新增“商家账号”：按登录邮箱录入采购者并在首次可信登录时绑定稳定身份，分别授予商品管理、订单发货、售后处理权限。支持地区筛选、启停、并发编辑冲突保护及操作记录；景泰／定边模板只填入模拟资料，不自动创建账号。
- 停用商家后禁止管理操作，隐藏其商品并拒绝新的购买请求；历史订单保留，由管理员处理。只有售后权限的采购者仅能看到自己的售后订单。账号资料与授权存在云端，本机静态模式不模拟真实授权。

云端后台新增“库存批次”：选择商品 → 设置库存 → 可点“填入模拟库存” → 核对两种规格、批次、日期和调整原因 → 保存。模拟按钮只填表，保存后才写入云端。**没有库存记录的商品默认可售数为0，需要设置后才能模拟下单**。按项目所有者要求提供一次性云端配置：仅为六款合格且从未配置的模拟商品各设置20／12份，配置完成关闭维护入口；已配置、已用完或有历史记录的库存均不覆盖。详见 [手机体验与库存配置](docs/DEMO-INVENTORY-SETUP.md)。旧订单保留且不会被迁移误扣库存，刷新或重新发布不会补满库存。

买家可查看规格余量、采收批次和日期，订单保留下单时的批次快照。取消时只有整单各商品均为原批次且可安全回补才归还；任一换批次则整单标记待采购者核对，不自动加到新批次。售后处理不自动回库，升级前没有库存快照的订单也不回库。当前只管理每款商品的一个在售批次，不是完整多批次仓储系统。

本机后台首次打开会补充带标记的示例订单，保留已有有效订单。云端不自动导入本地记录或生成示例订单；管理员可显式初始化六款模拟商品，已有商品保持原样。云订单由已登录买家在商城实际点击“模拟下单”生成。

## 历史网页云端开发与部署

云端需要安装依赖、配置运行环境和数据库迁移。本地云预览使用独立模拟资源；托管环境使用 Worker、D1、R2 和 Sites 提供的 ChatGPT 身份入口。公开仓库不含现成站点的内部身份或凭据，也没有自建密码或 OAuth 系统。

```sh
npm install
npm run setup:local
npm run build
npm run db:local
npm run dev
```

构建后的本地 Worker 可使用 `npm run preview:cloud` 预览；具体地址以启动输出为准。本地身份模拟不是实际登录，不能公开暴露预览服务。设置、管理员初始化、权限和故障处理见 [云端运行说明](docs/CLOUD-OPERATIONS.md)，已验证与尚未覆盖的设备范围见 [验收记录](docs/QA-2026-11-01.md)。

## 演示边界

商品、产地、规格、价格、运费和业务记录均为模拟，不代表真实货源、库存或采购合作。下单不扣款，发货不生成真实运单，售后不实际退款或补发，客服为本地自动回复。

本机模式的商品、订单等记录保存在 localStorage，文件在 IndexedDB，没有服务端授权。云端模式的商品、订单、发货与售后保存到 D1，上传素材保存到 R2；**购物车、收藏、足迹和示例地区偏好按登录账号保存到云端，客服对话仍只在当前页面**。匿名可浏览商品，登录后保存购物资料；不会导入以前的本机记录。跨设备冲突先读取核对，不静默覆盖。不要在演示订单中使用真实客户资料。

上传成功不等于发布：素材通过商品保存并上架后的绑定才公开读取。来源与授权说明由上传者填写，不代表已审核版权或核实货源。云端连接、鉴权或保存失败明确报错，不会静默改存本机；只有静态服务器返回明确演示标记才启用本机模式。

手机可使用有站点访问权限的同一账户访问托管原型，文件选择、播放和布局尚未实机验证；登录也不会迁移本机订单。克隆本仓库可独立运行静态演示。
