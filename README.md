# 陇上鲜集 / Longshang Fresh

从甘肃景泰起步的地方特产商城开源项目，逐步连接商品、产地内容、采购与订单服务。

**当前版本 V0.4 是浏览器演示：买家商城与管理后台在同一浏览器内联动。尚未发布为微信小程序，没有真实支付、云端账户或生产订单服务。**

## 快速开始

需要 Node.js 22 或更新版本及其自带的 npm。当前工程零运行依赖，无需执行 `npm install`。

```sh
git clone https://github.com/yegeli/longshang-fresh.git
cd longshang-fresh
npm start
```

启动后打开：

- 买家页面：[http://127.0.0.1:5173](http://127.0.0.1:5173)
- 管理后台：[http://127.0.0.1:5173/admin.html](http://127.0.0.1:5173/admin.html)，也支持 `/admin`。

使用同一地址来源打开买家和后台，才能共享本地数据。`localhost`、`127.0.0.1`、不同端口与线上站点各自保存独立记录。

## 已实现

- 五个买家入口：逛好物、特产馆、看产地、购物车、我的；支持搜索、分类、收藏、足迹和商品详情。
- 六款初始模拟商品：苹果、枸杞、梨、土豆、玉米、洋葱；后台可新增商品、编辑两种规格与价格、保存草稿、上架和下架。
- 商品图片可使用内置素材或选择本地文件，视频支持本地文件上传；保存商品后同步到同源买家页面与对应产地内容。
- 多商品、多规格合并生成模拟订单，只计算一次演示运费；保留下单时名称、规格和金额，后续改价不重算旧单。
- 后台可查看订单、保存备注、记录模拟发货、处理整单售后；买家可申请、撤回售后并查看处理意见。

初次打开后台会补充带标记的示例订单，保留已有有效订单。建议先从买家端下单，再到后台编辑商品、模拟发货或处理售后，最后返回买家端核对。

## 演示边界

商品、产地、规格、价格、运费和业务记录均为模拟，不代表真实货源、库存或采购合作。下单不扣款，发货不生成真实运单，售后不退款或补发，客服为本地自动回复。

商品、购物车、订单等记录保存在 `localStorage`，本地图片与视频保存在 IndexedDB。清理站点数据会丢失记录；当前没有跨设备同步、登录鉴权或服务端权限控制。不要将真实客户资料、密码或私密文件用于演示。

[旧版托管演示](https://jingtai-fresh-demo-1031.merry-brush-7565.chatgpt.site) 的版本与访问权限以托管设置为准。克隆本仓库即可独立运行，无需该托管服务。

## 开发与参与

```sh
npm test       # 模型、数据存储与本地 HTTP 服务测试
npm run check # JavaScript 语法检查及测试
```

测试通过后，仍需在浏览器检查文件选择、刷新恢复、视频播放和买家／后台联动；模型测试不能替代这些交互验收。

下一里程碑优先建设账户角色、服务端商品目录、素材与订单接口，以及权限和状态变更测试；通过验收后再开展小范围试运营。支付接入与企业注册不是当前开发里程碑的前置步骤。
