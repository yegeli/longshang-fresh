# 陇上鲜集 / Longshang Fresh

从甘肃景泰起步的地方特产商城开源项目，逐步连接商品、产地内容、采购与订单服务。

**V0.5 云端原型将商品目录、商家权限与素材接入服务端，同时保留 V0.4 本机演示。订单与售后仍是本浏览器模拟，没有真实支付、物流或生产订单服务，尚未发布为微信小程序。**

## 本机快速开始

需要 Node.js 22.13 或更新版本及其自带的 npm。运行静态演示无需安装云端框架依赖：

```sh
git clone https://github.com/yegeli/longshang-fresh.git
cd longshang-fresh
npm start
```

- 买家页面：[http://127.0.0.1:5173](http://127.0.0.1:5173)
- 管理后台：[http://127.0.0.1:5173/admin.html](http://127.0.0.1:5173/admin.html)，也支持 `/admin`。

该模式无需登录，只操作本浏览器演示数据。同一地址来源的买家和后台共享记录；`localhost`、`127.0.0.1`、不同端口与线上站点各自保存独立记录。源码在 `public/`，`dist/` 是云构建输出。

## 已实现的范围

- 买家五入口：逛好物、特产馆、看产地、购物车、我的；支持搜索、分类、收藏、足迹和商品详情。
- 六款模拟商品模板：苹果、枸杞、梨、土豆、玉米、洋葱；后台可新增商品、编辑两种规格与价格、保存草稿、上架和下架。
- 图片预设与文件上传、视频上传；保存并上架后，商品详情和对应产地内容读取同一素材绑定。
- 多商品、多规格生成合并模拟订单，只计算一次演示运费；保留下单时名称、规格与金额，后续改价不重算旧单。
- 本机后台支持订单备注、模拟发货和整单售后处理，买家可申请、撤回并查看处理意见。
- 云 API 支持平台登录状态、D1 角色与商品归属、版本冲突检查，以及 R2 素材上传和受控读取。普通登录账户无管理权，商家仅管理自己的商品与素材，管理员可管理全部商品。

本机后台首次打开会补充带标记的示例订单，保留已有有效订单。云端目录初始为空，不自动导入本地记录；管理员可显式初始化六款模拟商品，已有商品保持原样。

## 云端开发与部署

云端需要安装依赖、配置运行环境和数据库迁移。本地云预览使用独立模拟资源；托管环境使用 Worker、D1、R2 和 Sites 提供的 ChatGPT 身份入口。公开仓库不含现成站点的内部身份或凭据，也没有自建密码或 OAuth 系统。

```sh
npm install
npm run setup:local
npm run build
npm run db:local
npm run dev
```

构建后的本地 Worker 可使用 `npm run preview:cloud` 预览；具体地址以启动输出为准。本地身份模拟不是实际登录，不能公开暴露预览服务。设置、管理员初始化、权限、故障与验收见 [云端运行说明](docs/CLOUD-OPERATIONS.md)。实际托管部署和跨设备文件验收结果以对应发布记录为准。

## 演示边界

商品、产地、规格、价格、运费和业务记录均为模拟，不代表真实货源、库存或采购合作。下单不扣款，发货不生成真实运单，售后不实际退款或补发，客服为本地自动回复。

本机模式的商品、订单等记录保存在 localStorage，文件在 IndexedDB，没有服务端授权。云端模式的商品和素材保存到 D1／R2，**购物车、订单、售后、收藏与足迹仍只在当前浏览器，不随登录跨设备同步**。清理站点数据会丢失本地记录，不要在演示订单中使用真实客户资料。

上传成功不等于发布：素材通过商品保存并上架后的绑定才公开读取。来源与授权说明由上传者填写，不代表已审核版权或核实货源。云端连接、鉴权或保存失败明确报错，不会静默改存本机；只有静态服务器返回明确演示标记才启用本机模式。

[旧版托管演示](https://jingtai-fresh-demo-1031.merry-brush-7565.chatgpt.site) 的版本与访问权限以托管设置为准，不能据其推定当前云功能已上线。克隆本仓库可独立运行静态演示。

## 开发与参与

```sh
npm test       # 模型、存储、静态 HTTP 与云 API 测试
npm run check # JavaScript 语法检查及测试
```

云 API 测试使用 Node.js SQLite 执行实际生成的迁移，以适配器模拟 D1／R2，不访问生产资源。测试通过后，仍需在受信登录入口与真实浏览器检查权限、文件选择、刷新恢复、视频拖动和跨设备商品同步。

后续补齐服务端报价、订单归属和履约状态，再完善备份恢复与运维；云商品目录不等于真实交易能力。支付接入与企业注册不是本轮原型开发前置步骤。
